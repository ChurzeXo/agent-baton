解决多 AI 编程协作中最常踩的 3 大坑

🛡️

杜绝假装改完

以前 AI 经常说“已经改好”，实际根本没动文件。Baton 强制查验 Git Commit，没写真实代码休想交差。

💤

静默待机不耗电

不用死循环轮询，笔记本不再发烫。探针启动后 AI 彻底静默，等待期间零 CPU 占用、零 Token 浪费。

⚡

自动唤醒不用人肉搬运

接收方写完回执的一瞬间，发起方自动被唤醒继续干活，从此告别来回切换窗口复制提示词的繁琐。

日常使用只有 4 步

简单好记，不需要死记硬背复杂配置

1
创建任务单 明确任务目标与验收判据
baton new impl task "重构认证模块"
2
转递并启动探针 生成提示词，发起方自动静音待机
baton forward <ID> --wait
3
接收方提交真实证据 必须附带 Git Commit 与变动文件
baton receipt <ID> --evidence-paths "..."
4
自动唤醒闭环 发起方自动苏醒，确认改动合入
baton accept <ID> -n "验收通过"
