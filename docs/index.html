Why Multi-Agent Systems Fail Without Baton

Autonomous AI agents are brilliant coders but disastrous self-governors. Baton replaces polite chat with cryptographic discipline.

❌

Hallucinated Completions

Agent says "Refactored user auth & all tests pass", but touched zero files. Naive frameworks take its word and close tasks.

🛡️ Evidence-First Gate: Requires real Git commits verified via git cat-file -e.
❌

Sycophancy & Priming Bias

Reviewer agent reads the author's internal chain-of-thought and flatters its shortcuts ("Great explanation, accepted!").

🙈 Double-Blind Audit (--blind): Automatically strips <thinking> and prose excuses.
❌

Self-Signing Loopholes

A single rogue agent script switches its role flag, reviewing and approving its own PR without independent oversight.

🔐 Audit Nonce Challenge: Ephemeral cryptographic tokens block same-session self-signing.
❌

Polling Loops & Token Drain

Waiting for async peer tasks using continuous polling loops overheats the laptop CPU and drains thousands of tokens.

⚡ 0-Token Reactive Sleep: OS kernel events (fs.watch) wake up the agent in milliseconds.

The Deterministic 4-Step Lifecycle

Every baton pass advances strictly through a 4-state state machine.

STEP 01

Draft Ticket

baton new audit task "Auth Refactor"

Author specifies objective acceptance invariants and constraints.
STEP 02

Double-Blind Transfer

baton forward <id> --blind --wait

Strips cognitive biases, issues Audit Nonce, and sleeps at 0 Token.
STEP 03

Independent Audit

baton receipt <id> --nonce ...

Auditor independently runs shell test suite; submits Git proofs.
STEP 04

Reactive Wakeup

baton accept <id>

Author wakes up in milliseconds, verifies invariant report, and closes.

CLI Command Quick Reference

Clean, memorable, zero-dependency. Works with baton or handoff.

Command Description
baton init [--cross] Initialize intra-repo .handoffs/ or central cross-repo hub
baton status [--for <lane>] Inspect pending tickets assigned to your lane or repo
baton status --mermaid Render live multi-agent choreography topology flowcharts
baton new <lane> <type> "<title>" Create structured handoff ticket
baton forward <id> --blind --wait Transfer ticket, sanitize <thinking>, and sleep until reply
baton receipt <id> --evidence-... Submit verified receipt with Git commit SHA and file paths
baton check Run workspace invariant & preflight checks (must exit 0)
baton link Self-heal and wire baton shims to user PATH
